NIDHII BIRTHDAY WEBSITE
========================

Files:
- index.html
- nidhii.jpg

How to use:
1. Keep index.html and nidhii.jpg in the same folder.
2. Open index.html in a browser to preview it.
3. To share it as a public website, upload the folder to any static website host.

The birthday melody is generated in the browser, so there is no separate music file.
